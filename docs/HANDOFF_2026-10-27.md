## 8. Traps already hit (do not repeat)

- **Wrong repo:** on 24 Oct website files were pushed into the RR API repo and the API Worker lost all its secrets (`/api/prices` gave `500 not_configured`). Check the folder before every command.
- **Silent deploy failures:** an old `ship.sh` hid a failed wrangler deploy. Always read the real result (check-run status, hash, smoke test).
- **The checkout says "Online ordering opens soon":** not a bug. `/api/health` reports `live:false` until D1 and KV are bound, `TOKEN_SECRET` is set, and `ONLINE_ORDER_LIVE` allows it.
- **Push refused (403):** the session needs the repo attached with push access, or Claude's GitHub App installed on that account. For swagramam a collaborator invite to `bjnexusai-ai` was needed first.
- **Killing the dev server:** `pkill -f "dev-server.mjs"` inside the same shell command also kills that shell (exit 144). Stop it in a separate call.
- **Kit false results:** the site kit passed analytics on the `G-XXXXXXXXXX` placeholder and failed the checkout's intentional noindex. Use the improved kit in `tools/sitegate/` (`noindex_pages`, `whatsapp_also`, placeholder check, gzip-aware mobile check).
- **CSS through the browser:** never re-save CSS via the browser's CSSOM (it grew the RR file). Edit as plain text.
- **Tests with a fixed clock:** database views that use the database clock fail under a pretend clock (RR open-order cap). Count with the handler's `now()`.
- **Old instructions:** RR's `CLAUDE-README.md` and `RR-DURBAR-STATUS.md`, and old zips, point at the retired BJNEXUS account and old URLs. Ignore them.
